# DeskNX — матрица совместимости (ТЗ 1.3)

Этот файл — единственный источник правды о том, на каких конфигурациях
системный режим **проверен на физическом железе**. Всё, что не отмечено
здесь как «проверено», считается **непроверенным**, и README обязан это
говорить. Standalone NRO-режим менее чувствителен к версии Atmosphère,
но тоже зависит от libnx/SDL2.

## Версии по умолчанию

| Компонент | Значение по умолчанию | Источник |
|---|---|---|
| Atmosphère (`atmosphere_ref`) | `1.12.1` | workflow input `atmosphere_ref`, Build experimental DeskNX HOME backend |
| libnx (`libnx_ref`) | зафиксированный commit | workflow input `libnx_ref` |
| Целевая прошивка HOS | 18.x (на которой собран AtmosphereLibs дефолтного ref) | косвенно, из atmos-libs |

Сборка против других refs возможна через входы CI `atmosphere_ref` и
`libnx_ref`; успешная компиляция **не является** доказательством
runtime-совместимости.

## Проверено на железе

| Прошивка | Atmosphère | Режим | Статус | Дата | Примечание |
|---|---|---|---|---|---|
| — | — | standalone NRO | ❌ не проверялось автором ТЗ | — | ожидается первый smoke-тест |
| — | — | system HOME (qlaunch override) | ❌ не проверялось | — | ни один backend не запускался на реальном Switch |

> На момент версии 1.0 черновика **ни одна** строка не помечена
> «проверено». Системный режим остаётся экспериментальным; установка
> только на восстанавливаемую консоль с рабочим доступом к SD.

## Известные ограничения по версиям

- **ECS (`ldr:shel` + external content)**: API менялся между
  Atmosphère 1.0–1.4 и 1.5+; код пишет под интерфейс 1.9+. На более
  старых forks регистрация ECS должна падать с логом и приводить к
  слот-fallback (BK-11), а не к brick.
- **pmshell**: отсутствует на всех релизах Atmosphère до 1.x с shell2;
  считается некритичным сервисом (BK-02) — при его отсутствии
  мягкое закрытие игр деградирует до Terminate по таймауту.
- **Библиотечные апплет-слоты** (Album/Friends/Web/Blessing): набор
  AppletId стабилен с HOS 4.0; меню использует список из
  `ExternalContent.hpp` (BK-14).
- **NPDMDeskNXMenu**: разрешение `ForceDebug` удалено; на прошивках,
  где отладочные флаги обязательны для ECS-override, системный режим
  может не запуститься — фиксируйте это здесь после проверки.

## Как обновлять этот файл

После каждого hardware-test: добавить строку в таблицу «Проверено»
(прошивка, Atmosphère, режим, дата, кто тестировал, артефакт сборки).
При обнаружении регрессии версии — перенести конфигурацию в раздел
«Известные ограничения» со ссылкой на issue.
