# Персонализация DeskNX

Это руководство относится к текущей SDL2-версии DeskNX. Настройки лаунчера хранятся отдельно от раскладки рабочих столов, поэтому изменение темы, фона или шрифта не перестраивает плитки и не меняет их позиции.

## Где находятся настройки

Все ресурсы пользователя располагаются на SD-карте:

```text
sdmc:/switch/DeskNX/
├── settings.ini
└── media/
    ├── wallpaper.jpg
    ├── fonts/
    │   └── MyFont.ttf
    └── iconpacks/
        └── MyPack/
            ├── 0100000000001000.png
            ├── 0100000000002000.jpg
            └── demo.png
```

Скопируйте файлы в папку `media`, откройте **DeskNX Settings** из нижней панели и выберите нужную настройку. Настройки сохраняются в `settings.ini`; файл публикуется через временный файл и резервную копию.

## Темы

Доступно пять палитр:

- Frosted Glass — светлая стеклянная тема, используется по умолчанию.
- Graphite — нейтральный тёмно-серый вариант.
- Violet — фиолетовые оттенки.
- Sunset — тёплый градиент.
- Ocean — исходная синяя палитра.

Пункт **Change color theme** циклически переключает тему. После выбора она сохраняется и применяется при следующем запуске.

## Пользовательский фон

Поддерживаются статические изображения:

- JPEG/JPG;
- PNG.

Проводник показывает файлы из `sdmc:/switch/DeskNX/media` и вложенных папок. Изображение загружается один раз в текстуру, а в кадре используется готовая текстура с кадрированием по принципу cover. Ограничения безопасности текущей версии: не более 24 MiB на сжатый файл, до 4096×4096 пикселей и до 16 миллионов пикселей.

**MP4 пока не поддерживается.** В SLauncher видеообои используют отдельный NVDEC/FFmpeg-стек, связанный с SDL3 и платформенным аппаратным декодером. В DeskNX пока нет такого видеоконвейера; пункт выбора видео не показывается и видеофайл не будет ошибочно принят за статичную картинку. Добавление MP4 требует отдельной реализации декодирования, планирования кадров и проверки лицензий/зависимостей.

## Шрифты

Пользовательский шрифт можно выбрать из файлов:

- TTF;
- OTF;
- TTC.

Шрифт загружается через SDL_ttf и кэшируется для размеров текста, используемых интерфейсом. При ошибке загрузки DeskNX возвращается к системному шрифту, не блокируя запуск.

## Наборы значков и обложек

Откройте **Choose icon pack**. Проводник начинается в:

`sdmc:/switch/DeskNX/media/iconpacks`

Создайте внутри отдельную папку для набора, например `MyPack`, и выберите эту папку. Набор можно использовать без изменения стандартного кэша иконок.

Поддерживаются следующие имена:

| Тип | Имя файла |
|---|---|
| Установленная игра | `<TITLEID>.jpg`, `<TITLEID>.png` или `<TITLEID>.jpeg` |
| Homebrew NRO | `<имя_файла_без_.nro>.jpg/png/jpeg` |
| Homebrew — резервный вариант | `nro-<16-значный FNV-1a hash пути>.jpg/png/jpeg` |

Пример: если Title ID игры равен `0100000000001000`, значок называется `0100000000001000.png`. Для `sdmc:/switch/apps/demo.nro` подойдёт `demo.png`.

Кэш разрешённых путей и текстур очищается при смене набора. Файлы из пользовательской папки не удаляются при ошибке декодирования. Поддерживаются JPG/JPEG и PNG размером до 2 MiB и с разрешением не более 1024×1024.

## Виджеты

В каталоге виджетов доступны:

- Clock — текущее время и дата.
- Battery — заряд батареи.
- System — панель системных инструментов DeskNX.
- Recent — последние запущенные игры и Homebrew.
- Storage — свободное место и заполнение SD-карты.
- Calendar — текущая дата и день недели.

Storage обновляет данные не чаще раза в 10 секунд; виджет не вызывает `statvfs` на каждом кадре. Виджеты можно добавлять через пункт **Add widget to workspace** или через фильтр Widgets в библиотеке.

## Отзывчивость и производительность

Интерфейс использует следующие механизмы:

- VSync-рендерер не получает дополнительную принудительную паузу после Present; программная задержка применяется только при fallback на renderer без VSync.
- Рисование скруглённых карточек сокращено до центральной заливки и линий по углам.
- PDM-статистика выбранной игры запрашивается после короткой паузы в отдельном потоке, а не в обработчике прокрутки каталога.
- Иконки остаются в ограниченном текстурном LRU-кэше; разрешённый путь пользовательской иконки вычисляется один раз на сочетание типа элемента и его ID/пути.
- Стрелочная навигация повторяется после короткой задержки, чтобы ускорить работу с большим списком.

Фактический FPS, задержки SD и поведение сенсорного управления зависят от консоли, типа запуска и SD-карты. CI проверяет компиляцию и host-тесты, но не заменяет измерения на физической Nintendo Switch.


## Настройки отдельных рабочих столов

У каждого рабочего стола есть независимые визуальные параметры. Откройте меню рабочего стола (**... → Customize desktop**):

- **Desktop background** — отдельный JPG/PNG-фон из `sdmc:/switch/DeskNX/media/`.
- **Background fit** — Cover (заполняет экран с обрезкой), Contain (показывает целиком) или Stretch.
- **Game art fit** — Cover, Contain или Stretch для изображений игр и homebrew.
- **Title overlay** — плотность полупрозрачной подложки названия.
- **Accent color** — автоматический цвет плитки или общий цвет рабочего стола.

Параметры сохраняются вместе с раскладкой. Старые DESKNX1–DESKNX3 читаются и мигрируют в DESKNX4.

### Отдельные обложки игр

В выбранной папке icon pack можно хранить квадратные иконки как раньше (`<TITLEID>.jpg/png`) и отдельные обложки. Для обложки используются имена `cover-<TITLEID>.jpg/png`, `<TITLEID>-cover.jpg/png`, `<TITLEID>_cover.jpg/png` или `covers/<TITLEID>.jpg/png`. Обложка имеет приоритет над квадратной NACP-иконкой.


## Быстрая работа и сохранение

- Состав рабочих столов, названия, позиции плиток и оформление сохраняются в атомарную раскладку.
- При переключении стола обновляется только компактный маркер активного рабочего стола; полный файл и резервная копия не переписываются без изменений содержимого.
- Обложки подгружаются постепенно: сетка остаётся интерактивной, пока изображения появляются.
- Тёплый каталог приложений публикуется без предварительного перечитывания всех JPEG-заголовков; проверка и декодирование иконок выполняются по мере необходимости.
