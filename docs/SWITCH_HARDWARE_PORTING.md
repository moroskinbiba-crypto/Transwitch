# DeskNX: Архитектурное руководство по портированию на реальную консоль Nintendo Switch

Данный документ описывает полное техническое решение для переноса **DeskNX** на реальное железо Nintendo Switch (ревизии Erista v1/v2, Mariko, Switch OLED и Switch Lite) под управлением кастомной прошивки **Atmosphère CFW**, с сохранением 100% функционала: рабочих столов, анимаций, масштабирования плиток (1×1, 2×1, 2×2, 2×3), сенсорного перемещения пальцем (iOS Springboard style), чтения системного времени игры и управления программами.

---

## 1. Стратегия интеграции с операционной системой Horizon (Horizon OS)

Для работы в качестве полноценного лаунчера на Switch существует два пути:

### Вариант 1 (Рекомендуемый): Замена системного HOME-меню (qlaunch Title Override)
* **Title ID:** `0100000000001000` (системный апплет `qlaunch` — официальное HOME-меню Nintendo Switch).
* **Принцип работы:** Atmosphère подменяет исполняемый файл `exefs.nsp` по пути `sdmc:/atmosphere/contents/0100000000001000/`. При нажатии физической кнопки HOME на правом джойконе консоль мгновенно возвращается в DeskNX.
* **Failsafe (защита от кирпича/краша):** В коде загрузчика прописывается проверка зажатой клавиши `R` при запуске консоли: если `R` зажата, кастомный лаунчер пропускается и загружается оригинальный `qlaunch`.

### Вариант 2: Автономный лаунчер (Homebrew Application Title Override)
* Запуск через режим полного доступа к оперативной памяти (переопределение любой установленной игры с зажатой кнопкой `R`, Title ID `010000000000100D` или любая купленная цифровая игра).
* Обеспечивает доступ ко всем 3.2 ГБ доступной оперативной памяти Switch (в отличие от апплет-режима, где доступно лишь 450 МБ).

## 2. Графический стек и движок интерфейса: Как не потерять ни одной функции

Чтобы перенести плавные анимации размытия (frosted glass), свайпы столов, перетаскивание плиток пальцем и кастомизацию без полугода переписывания CSS-шейдеров на чистый C++/NVN, используется **архитектура гибридного рантайма (WebKit WPE / Ultralight + libnx)**, аналогичная той, что сделала революцию в проекте **uLauncher for Switch**:

### Стек WPE WebKit / Chromium Embedded + libnx
1. **Рендерер:** Оптимизированный порт **WPE WebKit** под Tegra X1 (Maxwell GPU) с аппаратным ускорением через EGL/Mesa/Nouveau или прямым контекстом NVN.
2. **Разрешение:**
   * Портативный режим: 1280×720 @ 60 FPS (7-дюймовый OLED или 6.2-дюймовый LCD).
   * Док-станция: 1920×1080 @ 60 FPS.
3. **JavaScript Engine:** JavaScriptCore с JIT (на Atmosphère с включенным `jit_debug`), обеспечивающий мгновенный отклик интерфейса.
4. **Сенсорный ввод:** Системный сервис `hid` передает координаты пальцев прямо в WebKit Touch Events (`touchstart`, `touchmove`, `touchend`), гарантируя точное перемещение плитки за пальцем.

## 3. Взаимодействие с системными сервисами Horizon OS (IPC libnx)

Все виджеты и функции DeskNX напрямую транслируются в вызовы C/C++ библиотеки **libnx**:

| Функция DeskNX | Системный сервис Horizon OS | Функция libnx |
|---|---|---|
| **Учет игрового времени** (playtime) | `pdm:qry` (Play Data Manager) | `pdmqryQueryPlayDataByApplicationId()` возвращает точные секунды в игре и число запусков. |
| **Параметры программы (+ / -)** | `ns:dev` / `am` (Applet Manager) | Вызов системного апплета `0100000000001007` (Data Management) или отображение диалога удаления кэша/обновлений. |
| **Запуск игр** | `am` / `ns` | `appletRequestLaunchApplication()` запускает выбранный `TitleID` без возврата в stock меню. |
| **Запуск Homebrew (.nro)** | Chainloader / `nx-hbl` | Передача пути к `.nro` в `sdmc:/atmosphere/reboot_payload.bin` или запуск через целевой `fsp-srv`. |
| **Заряд батареи и Joy-Con** | `psm` (Power State Manager) + `hid` | `psmGetBatteryChargePercentage()`, `hidGetJoyConRailIsConnected()` для левого/правого джойконов. |
| **Свободное место на диске** | `fsp-srv` (File System Proxy) | `fsFsGetFreeSpace()` отдельно для NAND (USER) и SD-карты. |
| **Кнопки L / R и геймпад** | `hid` (Human Interface Device) | `hidScanInput()`, `hidKeysDown(CONTROLLER_P1_AUTO)` опрашивает `KEY_L` и `KEY_R`. |
| **Режим сна / Перезагрузка** | `spsm` (Sleep & Power State Manager) | `spsmRequestSleep()`, `spsmRequestReboot()`. |

## 4. Спецификация хранения столов: Формат DESKNX4

DeskNX использует формат `DESKNX4` в текстовом файле `sdmc:/switch/desknx/layout.tsv`. Это позволяет мгновенно сохранять и восстанавливать расположение столов и плиток:

```tsv
DESKNX4
A	0
D	Главный стол		0	0	196	-1
D	Homebrew Софт		0	0	196	1
I	0	G	The Legend of Zelda: Tears of the Kingdom	0100F2C0115B6000	0	0	2	3	0
I	0	B	Батарея Switch & Joy-Con		2	0	2	1	0
I	0	C	Часы и время		4	0	2	1	0
I	0	G	Super Mario Odyssey	0100000000010000	2	1	2	2	1
I	0	G	Metroid Dread	010093801237C000	4	1	2	2	4
```

### Размеры плиток:
* **1×1** — компактный квадрат для небольших утилит и игр.
* **2×1** — классический горизонтальный виджет (аккумуляторы, часы, системные инструменты).
* **2×2** — средний квадратный виджет / постер игры.
* **2×3** — полноразмерный вертикальный бокс-арт Switch-игры (высотой во всю сетку стола), полностью повторяющий оригинальную коробку картриджа Nintendo Switch.

## 5. Сенсорное перемещение (iOS Springboard Touch Drag) на Switch

На емкостном экране Nintendo Switch (поддерживает до 10 одновременных касаний):
1. **Удержание (350мс):** Вибрация джойконов через HD Rumble (`hidSendVibrationValues`), переход сетки в режим редактирования (Wiggle/Jiggle).
2. **Следование за пальцем:** Выбранная плитка отрывается от сетки, увеличивается на 6%, получает полупрозрачную тень и аппаратно следует за координатой касания через CSS 3D Transform (`translate3d(x, y, 0)`).
3. **Динамический слот:** Под плиткой подсвечивается свободная ячейка сетки (`Сюда` синим или `Занято` красным).
4. **Перелистывание экранов:** При поднесении пальца с плиткой к границе экрана (< 55px) рабочий стол переключается влево или вправо на соседнюю страницу.
5. **Отпускание:** Плитка с пружинной физикой встает на новое место в сетке, координаты немедленно сохраняются в `layout.tsv`.

## 6. Пошаговая инструкция по сборке пакета под Atmosphère

1. **Компиляция Web-ресурсов:**
   ```bash
   npm run build
   # Результат попадает в папку dist/
   ```
2. **Упаковка в NX-пакет:**
   Исполняемый файл раннера `desknx.nro` компилируется с помощью **devkitA64** и **libnx**:
   ```bash
   make -f Makefile.switch
   ```
3. **Размещение на SD-карте консоли:**
   * Для автономного запуска: `sdmc:/switch/desknx/desknx.nro` + папка `romfs/` с содержимым `dist/`.
   * Для полной замены HOME-меню: `sdmc:/atmosphere/contents/0100000000001000/exefs.nsp`.
