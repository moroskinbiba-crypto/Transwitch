# Этап 1 — проверка базовой замены HOME

Этот чек-лист проверяет только базовый жизненный цикл: загрузка DeskNX,
передача foreground между HOME и игрой, запуск установленной игры, запуск
homebrew в applet mode и возврат в DeskNX.

<badge>Не проверено на физической консоли</badge>

Компиляция NRO, library applet и qlaunch backend в CI не означает, что этот
сценарий работает на конкретной Switch. Заполняйте чек-лист только после
фактического теста на устройстве.

## Перед началом

- [ ] Есть полный бэкап SD и проверенная возможность восстановить оригинальный qlaunch override.
- [ ] Консоль восстанавливаемая; не рассчитывайте только на аварийную комбинацию клавиш DeskNX.
- [ ] Сборка DeskNX соответствует установленной версии Atmosphère и прошивке HOS.
- [ ] Записаны версия HOS, версия Atmosphère, commit DeskNX и ref libnx из CI.
- [ ] Для проверки подготовлены две установленные игры: одна с существующим сохранением, другая для проверки первого запуска.
- [ ] Подготовлен простой homebrew NRO, рассчитанный на applet mode.

## Проверка

- [ ] **Холодная загрузка.** После включения консоли открывается DeskNX, меню отвечает на кнопки и сенсор, не остаётся чёрного экрана.
- [ ] **Запуск установленной игры.** Игра с существующим сохранением запускается из DeskNX, пользовательский профиль выбирается корректно, игра получает управление.
- [ ] **HOME из игры.** После завершения первоначального запуска игры (не раньше чем через 1,5 секунды) нажатие HOME открывает DeskNX. Игра остаётся приостановленной, а не завершается.
- [ ] **Возврат в игру.** Повторное нажатие HOME закрывает DeskNX и возвращает управление той же игре без повторного запуска.
- [ ] **Естественное завершение игры.** Откройте DeskNX из игры, затем закройте игру штатным способом из меню. DeskNX должен восстановиться; предыдущий title-holder не должен блокировать следующий запуск.
- [ ] **Переключение игр.** Запустите первую игру, откройте DeskNX и выберите вторую. Первая должна быть безопасно завершена до запуска второй; не должно оставаться зависшего foreground или чёрного экрана.
- [ ] **Первый запуск и сохранение.** Запустите игру, для которой ещё нет сохранения на выбранном профиле. Если создание save data завершается ошибкой, DeskNX должен показать отказ, а не выдавать запуск за успешный.
- [ ] **Запуск homebrew.** Запустите NRO в поддерживаемом applet mode, дождитесь его интерфейса и завершите его штатно. DeskNX должен вернуться автоматически.
- [ ] **HOME из homebrew.** Во время работы NRO нажмите HOME. Сессия hbloader должна закрыться, ECS-отображение должно быть снято, DeskNX должен открыться снова.
- [ ] **Повторяемость.** Повторите циклы HOME → игра → HOME не менее десяти раз. Ни один цикл не должен оставлять старый holder, второй экземпляр меню или зависший ввод.

Полноценный full-RAM/donor-mode запуск homebrew в этой версии не поддерживается
и не является частью первого этапа.

## Что приложить при сбое

Сохраните без редактирования:

- `sdmc:/switch/DeskNX/logs/daemon.log` и, если есть, `daemon.prev.log`;
- `sdmc:/switch/DeskNX/logs/ecs.log` и, если есть, `ecs.prev.log`;
- точное время и номер пункта, на котором возник сбой;
- HOS, Atmosphère, ref libnx, commit DeskNX и ID CI-сборки;
- описание: была ли игра на экране, появился ли HOME, сохранилось ли управление.

При первом чёрном экране, зависшем holder или невозможности вернуться к игре
остановите дальнейшие циклы и восстановите предыдущую конфигурацию. Не
продолжайте тест, многократно переустанавливая qlaunch override.

## Граница первого этапа

Первый этап считается пройденным только после выполнения всех пунктов на
физической консоли и внесения конкретной комбинации HOS/Atmosphère в
[матрицу совместимости](COMPAT.md). Сон/пробуждение, долгий прогон и
автоматическое восстановление после аварий относятся ко второму этапу.
