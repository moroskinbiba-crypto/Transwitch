# Transwitch

**Transwitch — homebrew-каталог фанатских переводов для Nintendo Switch.**

Это нативное приложение `.nro`: каталог открывается на самой консоли, архив перевода скачивается по HTTPS и устанавливается в папку LayeredFS конкретной игры.

## Возможности текущей версии

- Каталог с фильтром по языкам.
- Обновление каталога через интернет.
- Загрузка ZIP, 7z и RAR-архивов с официальных страниц релизов авторов.
- Установка только в `atmosphere/contents/<TITLE_ID>/romfs/` выбранной игры.
- Проверка HTTPS-сертификата по встроенному набору корневых сертификатов.
- Защита от архивных путей с `..`, абсолютных путей и ссылок внутри архива.
- Резервные копии файлов, которые заменяются, и возможность удалить патч с восстановлением сохранённых оригиналов.

Интерфейс пока текстовый — это первая рабочая основа. В каталоге сейчас одна предварительно проверенная запись; для широкого охвата нужен отдельный этап сбора и проверки ссылок на фанатские патчи. Статус одной записи не означает, что совместимость с каждой версией игры уже протестирована на физической консоли.

## Как установить Transwitch

1. Откройте вкладку **Actions** в GitHub и выберите последний успешный запуск **Build Transwitch**.
2. Скачайте артефакт **Transwitch-nro** и распакуйте архив на компьютере.
3. Скопируйте `Transwitch.nro` на microSD в `/switch/Transwitch/Transwitch.nro`.
4. Запустите Homebrew Menu на Switch и откройте Transwitch. Для продолжительных загрузок и установки предпочтительно запускать Homebrew Menu через takeover обычной игры, а не из альбома.
5. Подключите консоль к Wi-Fi. В списке нажмите **Y**, чтобы обновить каталог.

Для работы с патчами требуется среда, поддерживающая homebrew и Atmosphère LayeredFS. Сам Transwitch не устанавливает CFW и не включает/выключает защиту консоли.

## Управление

| Кнопка | Действие |
|---|---|
| Вверх / вниз | Выбрать перевод |
| A | Открыть карточку; в карточке — начать установку |
| X | Переключить язык; в карточке — удалить перевод и восстановить резервные копии |
| Y | Обновить каталог из репозитория |
| B | Назад / выход |

После установки закройте игру и запустите её заново, чтобы загрузить перевод.

## Каталог переводов

Данные находятся в [romfs/catalog.tsv](romfs/catalog.tsv) и обновляются напрямую из ветки `main`. Формат подробно описан в [data/README.md](data/README.md).

Для добавления перевода создайте Issue по шаблону **Suggest a translation**. Нужна прямая ссылка на страницу автора или релиз, язык перевода, Title ID, версия игры и известные ограничения. Отдельно помечайте машинный и частичный перевод. Не называйте запись «проверенной», пока не проверены источник, архив и совместимость.

## Сборка из исходников

Нужен devkitPro с инструментами Nintendo Switch и библиотеками `libnx`, `switch-curl`, `switch-libarchive` и `switch-zlib`.

```bash
. /opt/devkitpro/switchvars.sh
make -j2
```

Скомпилированный файл: `Transwitch.nro`.

## Правила распространения

Transwitch хранит метаданные и ссылки на патчи, а не образы игр. В каталоге разрешены только файлы, нужные для локализации, при условии, что автор разрешает их распространение по указанной ссылке. Установщик не устанавливает NSP/XCI, игровые образы, прошивки или произвольные исполняемые файлы.

Встроенный CA bundle берётся из [curl.se/ca](https://curl.se/docs/caextract.html), данные сертификатов предоставлены Mozilla. См. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
