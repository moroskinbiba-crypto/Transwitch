# DeskNX

**DeskNX** — собственный рабочий стол для Nintendo Switch: несколько пространств, свободная сетка, пустые ячейки, изменяемые размеры элементов и виджеты.

> **Статус:** ранний native Homebrew-прототип. Он запускается как DeskNX.nro в поддерживаемой Homebrew-среде. Сейчас DeskNX не заменяет системное HOME-меню и не запускается сам по себе при холодной загрузке консоли. Системная интеграция не устанавливается автоматически.

## Функции прототипа

- Несколько рабочих столов: создание, переименование и удаление.
- Сетка 6 × 3, пустые ячейки остаются пустыми.
- Добавление установленных игр, Homebrew-программ и виджетов.
- Перемещение элементов кнопками и сенсорным экраном, в том числе между рабочими столами.
- Размеры плиток 1×1, 2×1, 2×2 и 3×2; занятые ячейки не перекрываются.
- Виджеты часов, заряда аккумулятора, системной информации и последнего запуска.
- Сохранение раскладки на SD-карту.
- Сборка `.nro` и SD-пакета через GitHub Actions.

## Сборка

Нужны devkitPro, devkitA64, libnx и SDL2 для Nintendo Switch.

    make -j2

После успешной сборки откройте Actions → Build DeskNX и скачайте `DeskNX-sdcard`.

## Важно

Эта версия — Homebrew-прототип. Она пока не заменяет qlaunch, не меняет Atmosphère и не обеспечивает автозапуск после холодной загрузки. Полноценная интеграция HOME требует отдельного daemon/applet-слоя и тщательно проверенного пути восстановления; см. `docs/HOME_INTEGRATION.md`.
